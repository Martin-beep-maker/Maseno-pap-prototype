# Maseno Pap - AI Past Paper Tutor
An AI tutor for Maseno students that turns blurry past paper photos into clear explanations.

## Problem
Past papers are shared as low-quality WhatsApp photos with no marking schemes.

## Solution
- Upload photo
- Llama 4 Vision for OCR
- Muse Spark for step-by-step solution in English & Kiswahili
- Generates practice questions

Tech: React, Python, Meta Model API
Author: Martin - Maseno University
